Forja no ha podido arrancar

La interfaz no se ha cargado. Casi siempre es porque la página no se está sirviendo desde un servidor web. Forja usa módulos de JavaScript, y los navegadores los bloquean cuando el archivo se abre directamente desde el disco (file://).

  • Si tienes el código: npm install y luego npm run dev.
  • Si has compilado con npm run build: la carpeta dist/ hay que servirla (npm run preview), no abrirla con doble clic.
  • Si ya la estás viendo en una web publicada: abre la consola del navegador (F12 → Consola) y mira qué error aparece.
